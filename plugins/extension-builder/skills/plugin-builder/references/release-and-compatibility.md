# 发布与兼容性

维护、升级、重命名、发布准备和实际发布前读取。源码维护不默认 bump 版本，也不等于已获安装或发布授权。

## 兼容清单

先读取已发布技术标识、组件调用名、市场条目、manifest、配置键/默认值、持久数据、README 用法、网站详情路径及已有回归。列明改变与保留的行为，保护用户修改。

确需更名或移动时同时分析安装身份、Skill/Agent 调用、配置和数据、市场 source 与网站旧 URL。不假定市场 renames 自动处理 website。选择兼容层、迁移或保留旧标识是用户决策，不擅自迁移。

组件源码、插件安装副本和用户过程文档分开：文档配置不迁移源码；安装缓存可能可替换；过程证据不自动进入发布包或公开提交。真实数据才需要备份/迁移/回退，不为无数据组件增设状态系统。

## 发布准备

在授权范围内核对 manifest 名称、版本、说明、仓库地址、关键词和许可证；README 符合公共模板分工；CHANGELOG 明确未发布或实际发布状态，不编造发布日期。版本升级按真实对外契约与仓库策略讨论，不机械套用 major。

许可证改变只限用户批准对象；新增插件的 MIT 不改变市场仓库或旧工具许可证。发布前确认包内资源完整，无绝对本机路径、秘密、个人数据或无关测试产物。

## 实际发布门禁

安装/激活、Git 提交、推送、部署和发布分别列出动作、目标、权限、副作用、回退和验证，只有明确授权才执行。未发布实现可以交付，但不得称已上架或已运行验证。

本 Builder 自维护保留旧工具，使用稳定已加载指引；新角色与新源码在获准独立会话验证，不能用本轮自举工具冒称它们已真实加载。切换和删除旧副本另行批准。
