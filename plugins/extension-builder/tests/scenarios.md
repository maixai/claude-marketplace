# 首版验收场景

本文件是规格，不是通过报告。**下列所有行为、宿主和网站用例均未执行**；静态读到规则不算行为通过。结构脚本单测可独立运行，其结果只覆盖检查器，不覆盖 Builder 交互。

## 执行前提与判据

- 真实模型请求另确认方式、场景、隔离、凭证来源、预算和停止条件。遵守项目凭证规则，不使用真实秘密夹具或个人配置。
- 确认真正加载目标插件、入口与四角色；其它 Agent 读文件模仿只能叫提示词演练。记录配置模型与可观察路由，未知不猜。
- 多轮批准逐阶段输入，不提前泄露未来批准。每阶段保留工具轨迹、文件清单/内容差异和输出。
- 不修改的断言检查实际文件和工具，不能只看回答；允许写工具后观察主动守门，权限拦截不能证明批准纪律。
- 每项绑定产物状态、实际命令/操作和原始结果。修订后重跑受影响项，未验证、失败、阻塞和不适用分别说明。
- 网站端到端使用真实插件数据；非交互 eval 不能证明 Monitor 交互、完整人工批准或浏览器。

## 有限结构检查器回归

`test_validate_skill_structure.py` 用标准库创建全新临时夹具，位于插件 tests 内并自动清理，不执行夹具代码。沿用旧 ST 编号，测试含精确断言，不以出现一行 PASS 作为覆盖判据。

| 编号  | 夹具或输入                                      | 断言                                                      |
| ----- | ----------------------------------------------- | --------------------------------------------------------- |
| ST-01 | 最小 SKILL 与存在引用                           | 无 fail，仍 YAML/Markdown/runtime unverified                |
| ST-02 | 缺 SKILL.md                                    | file_read fail，CLI 退出 1                                 |
| ST-03 | 空和全空白文件                                 | empty_file fail                                           |
| ST-04 | 非 UTF-8、空字节                               | file_read/text_encoding fail                              |
| ST-05 | 无起止分隔、空 frontmatter                      | frontmatter_delimiters fail                               |
| ST-06 | 重复缺失引用                                   | local_reference fail 只报一次                             |
| ST-07 | 批准范围外现存文件                             | scope fail，不读内容                                      |
| ST-08 | 文件/目录 symlink 越界                         | scope fail，不递归读取                                    |
| ST-09 | 范围内目录 symlink                             | directory_symlink unverified，不遍历链接                  |
| ST-10 | 动态/标题/括号/锚点/外部 URL                     | 相关项 unverified，不联网                                 |
| ST-11 | 围栏和行内代码伪链接                           | 不当真实引用                                              |
| ST-12 | allow-root 额外目录                             | 只核查引用，不全量扫描                                    |
| ST-13 | 精确 Agent 和脚本                              | 仅 Agent 必需 frontmatter；父目录不自动允许；脚本不执行    |
| ST-14 | 二进制和大于 1 MiB 文本                         | content unverified，不解码/无限读取                       |
| ST-15 | 分隔正确但 YAML 非法                           | yaml unverified，不误报语法 pass                          |
| ST-16 | 缺参数/未知参数                                | argparse 退出 2，无 JSON 报告                            |
| ST-17 | symlink 后接 .. 逃出范围                       | 按真实解析判 scope fail                                  |
| ST-18 | symlink 后接 .. 仍在范围                       | 无 fail，链接目录仍 unverified                           |
| ST-19 | 有效 Skill CLI                                 | unverified 退出 2 且存在有效 JSON                         |
| ST-20 | 同时 fail 与 unverified                         | fail 总状态和退出 1 优先                                 |
| ST-21 | 引用定义、百分号编码和空格路径                   | 正确核查本地引用                                          |
| ST-22 | 编码空字节链接                                 | local_reference fail                                     |
| ST-23 | 显式 component 是越界 symlink                    | 不因列出链接而自动批准目标                               |
| ST-24 | 精确 component 是目录                           | file_type fail                                           |
| ST-25 | Skill 目录不存在                               | skill_directory fail                                     |
| ST-26 | CLI skill-dir 含越界 link/..，绝对和相对输入     | scope fail；不读真实越界目标，也不改查词法同名目录         |
| ST-27 | CLI component 含越界 link/..，绝对和相对输入     | scope fail；词法同名文件不被误批准，相关引用不读           |
| ST-28 | CLI agent 含越界 link/..，绝对和相对输入         | scope fail；不改查另一 Agent，也不授权词法同名文件        |
| ST-29 | CLI allow-root 含越界 link/..，绝对和相对输入    | scope fail；不批准真实或词法替代根，不误读其引用           |
| ST-30 | 四类 CLI 参数含安全 .. 或范围内 link/..         | 绝对/相对形式均检查真实目标，无 fail，保持 unverified      |
| ST-31 | 显式 skill-dir/allow-root 本身是越界目录链接     | scope fail；不因列出链接就自动批准目标或替代根             |

ST-26—29 的夹具同时放置合法的词法同名文件和不同的真实目标，断言已读取/已核查成功的路径中没有两者；不能只断言退出非零而漏掉检查对象已被替换。ST-30 保留正常父目录输入的可用性，ST-31 保护原有显式 symlink 授权边界。

退出码 2 同时可能表示参数错误或有效 unverified 报告，必须检查输出类型。此脚本没有完整 YAML/schema/宿主/行为校验能力，单测通过不扩大它的范围。

## 少量可加载评测

`evals/` 提供只设计、不清楚先问、显式文件不重复拼接、已批准继续四个 case，各有 prompt 和 graders。它们尚未运行，仅覆盖对应的单轮分支；不代表上述整表已覆盖。后续多轮测试需分阶段供给批准，不能把未来批准预装到负例上下文。
