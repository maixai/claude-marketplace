# MCP 接入

本指引只负责获准的 MCP 配置与接入。开发完整业务服务是额外范围，不能由“接个 MCP”自行扩张。Builder 自身没有默认 MCP 依赖。

## 设计与取证

明确服务身份、传输、地址/进程、认证引用、作用域、工具命名、只读/写入范围、连接失败和断开/清理。按 [插件组件](https://code.claude.com/docs/en/plugins/components.md)、[manifest](https://code.claude.com/docs/en/plugins/manifest-reference.md) 和目标项目规则核对准确字段。

不将真实令牌放进示例、manifest、报告或日志；引用获准的环境/秘密来源即可，不扫描用户凭证。向外部服务传送项目内容需明确许可。

## 实施边界

配置文件与实际批准/启用/连接是不同阶段。现有设置中的拒绝不能通过另一 CLI、SDK 或临时连接绕过。只改获准条目，保留其它服务器和权限。插件 SubAgent 不能用自身 mcpServers 字段假建运行环境；需 Main 提供实际宿主能力。

生成目标变量时保留目标语义，不能提前替换成 Builder 安装路径或本机秘密。新依赖和后台进程先批准，不自动安装 server。

## 验证

- 静态检查配置与秘密引用，不把 JSON 可读当连接已成功。
- 获准连接后核实服务器身份、工具实际名称及可见权限。
- 使用非敏感受控输入验证目标工具、错误/超时/断开和重连；写操作需明确对象和授权，不为验收修改生产数据。
- 缺凭证、连接被拒或工具不可用时报告原始现象与未验证范围，不读取其它秘密补救。

maixai 网站读取 `.mcp.json` 的 `mcpServers` 映射展示类型与名称，不要求发明非官方 description 字段；其它声明方式不能假定已采集。
