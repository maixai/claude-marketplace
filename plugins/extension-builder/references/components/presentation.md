# 展示类扩展

目标涉及 Theme 或 Output style 时读取。它们与市场 website 展示不同，不用一套验收替代另一套。

## 设计与实施

确认目标是宿主界面风格还是回答风格，列作用域、选择/启用方式、输入输出、原行为保留、可逆性和可访问性要求。按 [插件组件](https://code.claude.com/docs/en/plugins/components.md) 的目标类型章节核对位置、配置及版本支持；未核实的 Theme/Output style 字段不猜。

维护时读取现状和调用配置，最小修改，不覆盖用户其它样式或输出偏好。生成资源保持可移植；是否启用新风格另行批准，不因为文件存在就改变用户当前设置。

## 验证

结构只证明文件符合所检查契约；真实宿主中选择目标并观察实际效果。Theme 检查可读性、明暗状态和目标环境布局；Output style 用代表性问题检查格式、内容保真与边界，不仅搜索关键词。记录目标版本、设置和效果证据，不能把主会话模仿风格当真实加载。

需要浏览器或其它当前角色不具备的工具时回 Main；无条件就报告未验证，不承诺已截图。maixai 当前网站不完整覆盖这些类型；有展示需求时先确认采集扩展范围，未经批准不改全站。
