# Builder 任务记录

仅在用户批准保存过程记录及具体位置后使用本模板。将占位项替换为事实，删去不适用栏目；未执行写未执行，不填预计成功。记录是恢复依据，不是授权令牌。

## 目标与状态

- 任务 ID、入口（component-builder/plugin-builder）：待填写。
- 用户原始目标与澄清记录：待填写可定位依据。
- 非目标、成功标准、操作类型：待填写。
- 宿主、版本、组件类型与作用域：待填写，未知明确注明。
- 当前阶段、已完成事项、阻塞、下一步：待填写。
- 本次改变、必须保留的行为、已有用户改动：待填写。

## 路径与配置来源

- 配置来源：当次显式 base / 原生 userConfig / 明确未设置时的默认值 / 已有任务，保留实际一项。
- `docs_base_dir` 原始值及是否已有效解析：待填写，不包含秘密。
- `workspace_anchor`：待填写任务开始时确认的绝对目录及确认依据。
- 解析后的绝对 base：待填写。
- 绝对 `task_dir`：待填写；已有任务沿用，不追加后缀。
- 显式已有方案文件（如适用）：待填写绝对路径。
- 源码根、允许文件/配置项、禁止范围：待填写，与文档位置分开。
- 真实路径、symlink、碰撞、权限和用户修改检查：待填写实际结果。
- 文档写入授权的用户依据、用途与数据边界：待填写；未批准就不使用本模板落盘。

## 交付、清理与恢复

- 交付文件、用法与各层验证结论：待填写。
- 未验证、遗留问题、偏差和用户接受的限制：待填写。
- 测试进程、临时配置、部分修改、清理与回退结果：待填写。
- 恢复时读取本记录、最终批准快照、实际产物和原始证据；核实可信用户批准，不凭 approved 字段继续。
- 沿用本记录绝对 `task_dir` 与 anchor，不因 cwd/worktree/配置/入口改变重算；跨机器路径失效请用户明确新位置。
- 并发变化、symlink 变化、批准对象不明或设计范围改变时暂停；迁移目录需另批，不覆盖或删除历史。
